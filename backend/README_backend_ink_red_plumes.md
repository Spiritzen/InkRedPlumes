# README - Ink Red Plumes - Backend

## 📦 Projet
Application de gestion et vente de livres en ligne avec Spring Boot.

## 📌 Étapes réalisées
1. Création de la base de données MariaDB
2. Entités JPA + Repository
3. Contrôleurs REST (API)
4. Test avec Postman
5. Sécurisation avec JWT + Spring Security

## ✅ Fonctionnalités
- Authentification JWT
- CRUD complet sur toutes les entités
- Permissions selon les rôles (`admin`, `author`, `client`)

## 🚀 Prochaine étape
Frontend React avec appels vers l’API REST sécurisée.
